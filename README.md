# Portfolio

## Description

Réalisation d’un portfolio personnel selon une démarche de gestion de projet professionnelle.  
Le travail a débuté par une analyse de portfolios existants et l’identification des bonnes pratiques, complétée par la création de personas et de user stories pour orienter la conception. 
Après la planification du projet et la gestion des contraintes, des maquettes ont été conçues avant le développement du site en HTML/CSS.
Une phase d’évaluation ergonomique a permis d’optimiser l’interface, la navigation et les contenus.
Le projet s’est conclu par la finalisation du site et la rédaction d’un bilan mettant en avant les choix réalisés et les axes d’amélioration.
